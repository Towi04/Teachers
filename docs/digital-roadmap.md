# Digital Roadmap

MyOwnMaterials should begin with printable materials. Digital activities should
be added after the platform has a stable reusable content library, template
system, public/private publishing rules, and print/PDF workflows.

## Online Session Model

Future live activities should wrap MyOwnMaterials activities in a session layer:

1. Teacher selects or creates an activity.
2. Teacher starts an online session.
3. The platform generates a short class code.
4. Students join from a phone, tablet, or computer.
5. Students complete the activity.
6. Teacher reviews basic results.

This session layer should belong to MyOwnMaterials, even if a future activity is
powered by H5P.

## Suggested Digital Phases

### Phase 1: Native practice mode

- Flashcard practice
- Vocabulary matching
- Simple quiz mode
- Self-paced links

### Phase 2: Live class mode

- Join codes
- Student nicknames
- Teacher lobby
- Basic participation and score reporting

### Phase 3: H5P playback

- Import `.h5p` files
- Render H5P activities inside MyOwnMaterials
- Keep H5P activities connected to the content library where possible

### Phase 4: H5P authoring

- Evaluate H5P.com versus a self-hosted H5P server.
- Support H5P editing without requiring Moodle.
- Capture results with xAPI-style events where supported.

## H5P Evaluation Notes

H5P can be useful as an advanced interactive activity engine, but it should not
replace the core MyOwnMaterials model.

MyOwnMaterials should own:

- Users and plans
- Reusable teacher content
- Public/private content rules
- Credits
- Templates
- Printable output
- Session codes and class participation

H5P can later provide:

- Advanced interactive content types
- Import/export interoperability
- Reusable digital activity patterns

## Product Boundary

Do not add H5P dependencies until the project explicitly enters the digital
phase. The printable MVP should remain lightweight and focused.
