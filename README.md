# MyOwnMaterials

MyOwnMaterials is a printable-first teaching material generator. Teachers add
their own content once, choose an activity, pick a template, and print
classroom-ready materials.

The current implementation is a Next.js prototype focused on the first product
phase:

- Reusable vocabulary/content collections
- Shared asset library concepts
- Flashcard generation
- Print/PDF-ready layouts
- Public/private content rules
- Freemium plan behavior
- H5P and digital activities documented as later phases

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the app.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```

## Product direction

The first version should stay focused on printable resources. H5P, live student
join codes, online quizzes, and LMS-style reporting are future digital features
after the printable foundation is stable.
